# 免费数据来源接入边界

当前无远程抓取实现，源目录仅作官方跳转。不要将网页可访问等同于有权批量提取或再发布。

接入流程：核验来源条款与许可 → 记录允许使用的字段、更新频率、缓存与再发布范围 → 编写单一来源适配器 → 生成独立候选快照 → Core.validate → 人工核验 → 后台发布。

来源应返回结构化候选值、sourceUrl、sourcePublishedAt（可空）、verifiedAt、提取方法与置信状态。不能更改未知原始日期，不能将比赛所在地全天日期硬转为北京日期。

先保留人工导入的免费路径。没有许可的来源保持 directory-only，不默认启用，也不承诺实时性。

未来自动合并必须实现字段级 manualOverride 锁、来源冲突队列、超时/重试、数据过期标记、变更审计；本版只支持整体快照和人工编辑，因此不存在自动覆盖人工值的后台任务。

建议禁止自动发布 demo 数据；微信发送前必须再次检查 meta.mode 和条目的 demo 标记。
